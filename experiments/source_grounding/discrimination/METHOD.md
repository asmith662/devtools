# Candidate-surface discrimination, prospective development procedure

This procedure replaces the unapproved chunked-04 design. That governed design
could require 84 fresh calls to answer a wider question than the immediate
source-grounding hypothesis. It remains historical, unexecuted prospective work.
This experiment asks whether purpose-relative own-source grounding discriminates
useful direct structural pursuits within the canonical lexical A/BROAD surface.
Repository-wide recall, global necessity, complete witnesses, complete task
sufficiency, evidence outside BROAD and production acceptance are out of scope.
Reach and completeness require a separately approved experiment if this evidence
justifies its cost. No A1, A2 or semantic consolidation is executed here.

The analysis unit is one case/obligation/source/target pair. Every native direct
Reference occurrence remains in its provenance; repeated occurrences are not extra
statistical units. Generation replays the unchanged canonical A and BROAD native
Reference definition, including the source-before-target condition. It never
reads grounding, QUALIFIED or gold. Both endpoints' complete contents appear once
in the blind disclosure, referenced through opaque keys. Address and native range,
route and declaration-key provenance describe the relation. Ranks, scores,
queries, canonical identities, treatment results and timings remain host-only.

Census is preferred. Every possible sample's input is bounded by a fitting census
input before sample selection. Output capacity determines a fixed stratum sample
size before random selection. Obligation-only stratified SRS without replacement
uses the seed in protocol.json and Python Random seeded by SHA-256 of seed, case
and obligation. Selected identities and inclusion weights are frozen. Allocation
first meets the worst-case binary 95% normal planning margin of 0.15 with finite
population correction, then increases the currently least precise stratum until
another pair cannot fit. This is a development planning approximation, not a
promise of subgroup precision. Cases 0023/0024 use a census; 0022 uses sampling.

One fresh Astra/High primary per case independently judges SOURCE_USEFULNESS,
TARGET_USEFULNESS and primary PURSUIT_VALUE as USEFUL, NOT_USEFUL or UNCERTAIN.
Own content materially helping the obligation defines endpoint usefulness;
following the disclosed native relation as a useful evidence-pursuit step defines
pursuit value. Labels cannot be derived from one another. Repeated endpoint/
obligation judgments must agree. The instruction and schema in gold.py are exact
scientific contracts. Each endpoint permits one exact quote anchor of at most 64
Unicode characters, and pursuit_reason permits 32. These purposefully compact
anchors locate an audited judgment in already disclosed complete content; they
are not summaries replacing source content. USEFUL requires an own-endpoint
anchor. The preferred 512-character ceiling was reduced prospectively to 64 to
meet one-call output capacity without removing any disclosed source content.
If adequate adjudication/audit representation cannot fit, representation_complete
must be false and the case fails incomplete. No truncation or label substitution.

Host resolves source_key/quote/occurrence by exact Unicode equality, left-to-right
code-point offsets, including overlapping matches (advance one code point after
each match). No normalization, fuzzy matching, inferred source or repair. Host
reattaches exact canonical source/start/end/quote. Same-primary self-review is
required; no other reviewer, reconciliation, fallback, or automatic retry.

Treatment scientific prompts, labels, eligibility and grounded-only QUALIFIED
remain unchanged. Immutable completed 0022/B and 0023/B are adopted with original
usage and provenance: no new judgment, Sol call, tokens or retroactive old
publication. 0024/B is one fresh Sol/High call. Total fresh maximum is four: three
Astra and one Sol. Each controlled turn has one reservation before scientific
entry. Provider transport retries remain built-in runtime behavior, unobservable
underlying request count UNKNOWN. Budget admission never grants science authority.

Design-aware Stage D joins only after independent sealed treatment and gold.
HT weighted ratios report resolved-gold useful-pursuit density by grounding,
risk difference, risk ratio where defined, useful-pursuit retention and exact
candidate reduction. Secondary endpoint densities and unique-target reduction
are reported; useful-target retention uses induced target/obligation inclusion
probabilities, avoiding counting targets as independent pair samples. Raw counts,
denominators, effective sample counts and uncertainty accompany estimates. Finite
population stratified delta-method uncertainty includes covariance. Census has
zero sampling error, not zero semantic uncertainty. Sparse/degenerate subgroup
intervals are unavailable; zero-denominator ratios are UNDEFINED. UNCERTAIN is
separate and never negative. Cohort estimates describe these finite candidate
populations, with case x obligation strata; no causal or confirmation inference.
Intervals condition on stable local labels and exclude model measurement error;
they are not gold-reliability or cross-repository confidence claims.
Noncensus normal approximations require at least ten observed domain units with
at least five outcomes on each side; otherwise intervals are explicitly unavailable.
These are prospective approximation safeguards, not scientific success thresholds.
Secondary source/target densities retain the pair analysis unit (a source with
several pursuits appears in several units); unique-target retention separately
uses its induced inclusion design. No independent-source sample is claimed.

Decision protocol is ESTIMATION_FIRST. Existing goals supply no defensible numeric
practical-effect thresholds for these new local labels. Inventing thresholds to
fit a sample or inspecting treatment to choose them would be retuning. Report
density effects, retention, reduction, cross-case direction and uncertainty to the
maintainer; no p-value-only gate or automatic production decision.

Exact input characters/UTF-8 bytes and constructive worst-case canonical response
bytes must pass before entry. Compatible input capacity is 700,000 chars/bytes;
method output ceiling is 65,536 bytes, with planned responses also below attained
63,357-byte certification. These separate empirical workload receipts are lower
bounds, not absolute model limits or an exact tokenizer. Runtime context catalog
does not replace exact execution-profile certification. Failure is incomplete,
never an invitation to add a call or switch to chunked gold.

Usage categories remain input, cached input, cache-write input, output and
reasoning output separately. UNKNOWN is not zero; no overlapping total, API cost
or subscription-quota inference. Invocation/stage/case/cohort burden is mandatory
before publication. Public economics use measured published calibration envelopes;
personal rolling/calendar reports stay ignored/local, bound by snapshot digest.
Numeric weekly limits remain UNSET; any later configured limit must pass along
with the exact four-call experiment reservation before launch. No capacity,
representation or budget failure permits automatic retry or incomplete success.
