# Frozen schemas and validation ownership

The executable schemas are strict allowlists in [reviewer.py](reviewer.py),
[contracts.py](contracts.py) and [workers.py](workers.py). Unknown fields, duplicate
or missing identities, stale native content/document/frame identities, foreign
obligations, non-original predecessors and unsupported Reference IDs fail closed.
There is no model score or implicit unresolved cell.

Both sterile packet kinds have exactly four files: packet.json, INSTRUCTIONS.md,
stage_c_builder.py, packet_integrity.json. The last binds the other three bytes;
the controller's immutable packet checkpoint binds all four. The builder is the
frozen standalone branch of the trusted codec and remains unchanged in the primary.
The deterministic two-branch projection removes the sibling schema, model and
judgment vocabulary before disclosure. Gold never receives grounding logic;
grounding never receives gold/witness logic. Preparation retains the trusted
full codec as reviewer_codec.py; this is not a semantic input.

`source-grounding-packet-v1` has schema/case/task/frame/cells. A cell has exactly
obligation={id,requirement,satisfaction,exclusions,gap} and source={address,
document_identity,content_identity,content}. It contains exactly the distinct
(obligation, source) membership in captured BROAD support. Its size is unknown
before acquisition. Completion compares exact expected and actual cell sets,
not a Cartesian product containing sources in obligations where they did not emit
qualifying support. No target, count, rank, query, graph or Reference metadata.

`blind-semantic-gold-packet-v1` has schema/case/task/frame/obligations/resources.
Resources use the same four source fields; the frame is the complete observed
parent universe. Gold completeness is resources x obligations. Full-frame hashes
are independently reconstructed from ordered address/content identities.

`blind-primary-review-v1` has schema/case/frame/packet_sha256/attestation/cells/
units/gaps/self_review. Grounding cells contain obligation/source/verdict/spans/
statement/reason/assumptions/uncertainty/additional_information. Gold cells contain
obligation/source/label/spans/reason. Units are forbidden in grounding; gold units
carry id/obligation/statement/basis/necessity/alternatives. Instructions specify
all exact verdicts, label semantics, gaps and required evidence.

A span has source={address,document_identity,content_identity}, integer character
start/end (end exclusive), and exact quote. Only that cell's own source can be
cited; gold unit alternatives may conjunctively cite multiple native resources.
An identity is never inferred from a path or an approximate quotation.

The seven primary scientific artifacts follow controller ownership. A frozen
builder deterministically derives statistics, Markdown, validation and hashes from
the primary review JSON; import preserves all seven original bytes. Every primary
is replayed in a separate process. Normalized validator receipts carry explicit
single-primary/model/blindness fields; packet and output JSON use NO_ACCESS strings
to avoid forbidden treatment-metadata keys. A truthful behavioral attestation is
required in addition to filesystem isolation, never claimed as an OS sandbox.

`source-grounding-captured-B-v1` preserves complete native A, every eligible BROAD
fact ID and original predecessor, then adds only QUALIFIED and uncertain-potential
subsets. Full native returns remain in the immutable journal; capture-time deep
correspondence seals their exact projection without reacquisition. Normal sealed
verification hashes files/proof and checks canonical joins with zero native decode.

`source-grounding-D-v1` performs exact case/frame/obligation/resource/content joins,
both target channels, grounding confusion counts, category boundaries and burden.
Its outputs and exact replay are deterministic over sealed B and imported C.
None of these schemas authorizes execution or changes production behavior.
