## Scientific channels

A is canonical native BM25, Unicode word spans and casefold, k1=1.2, b=0.75,
independent filename weight=0.25, the entire positive-match universe, native score
and tie order over address-ordered documents. No exact locator occurs in any task;
all authored needs route to lexical acquisition. No BM25F, task term weighting,
dense acquisition, PageRank, PPR, RRF, graph rank or output-based query revision.

BROAD is the unchanged 0017–0019 direct Reference mechanism: source and target
both belong to the same obligation's A, source != target, source A rank < target
A rank, with a positive resolved native declaration Reference, REFERENCER ->
DEFINER. Self References are descriptive only. No reverse/synthetic edge, other
relation family, second hop, proximity, test mirror, inheritance or graph admission.
Import/call routes retained by native Reference truth are provenance, not separate
treatments. A, BROAD and QUALIFIED are evidence surfaces; rankings never change.

Grounding candidates are the distinct (obligation, source) cells emitting at least
one qualifying BROAD relation. Membership is computed only during future B; Stage A
does not calculate its size. Each case uses one fresh GPT-6 Sol / High invocation,
one primary, no continuation, second reviewer, reconciliation or automatic retry.

GROUNDED_SOURCE: own content establishes concrete current-repository facts materially
useful for understanding or satisfying O. NOT_GROUNDED_SOURCE: it does not.
UNCERTAIN_SOURCE: plausible relevance but insufficient own disclosed content for a
confident conclusion. Filename, edit-location guess, lexical rank, graph degree or
target prediction alone cannot establish grounding. Grounded judgments require exact
own-content character spans with quote, a factual statement, relation to O,
inferability assumptions and uncertainty. Negatives need a reason; uncertain cells
need precise uncertainty and additional information needed, if identifiable.

QUALIFIED = BROAD restricted to sources GROUNDED_SOURCE for that exact obligation.
Uncertain and negative sources emit no primary qualified support; uncertain potential
support is retained descriptively. No score, fractional weight, promotion or swap.
Targets stay inside A. Removing annotations must reproduce exact captured A.
Both channels use the same original predecessor at target rank minus one.

## Disclosure and independent gold

Current semantic transport is [host disclosure](../orchestration/engineering/host_disclosure/README.md).
Models choose exact quote content and an explicit overlapping occurrence using
opaque packet-local source keys. The host deterministically derives the original
canonical identities and Unicode spans, writes the review and runs the unchanged
scientific validator. Invalid locators fail without repair. This changes execution
and representation ownership, not grounding/gold meanings or disclosed content.

The grounding packet is one complete case batch of independent source/obligation
records. Each contains only case/task, obligation criteria/exclusions/gap, native
source/document/content identity and full source content. Neither InformationNeed
nor raw query is disclosed: O supplies semantic purpose; queries are Retrieval's
serialization and could bias Localization. No targets, target content/ranks/counts,
References, reached declarations, occurrence counts, graph neighborhood,
predecessors, other-source verdicts, gold, other case or child state.
Full source text is not scrubbed: natural import names and paths are content,
not disclosure of computed structural treatment metadata. Batch judgments must
cite only their own source; another record's verdict cannot be an evidence premise.
Packet membership reveals selection as a source candidate, but no further reason.

Stage C uses one fresh independent GPT-6 Astra / High primary per case. It receives
task, obligations/criteria/exclusions/gaps and the complete parent resource frame.
It receives no needs/queries, A/ranks/scores, source-candidate categorization,
grounding results/rationales, BROAD/QUALIFIED evidence, Reference treatment,
predecessors, timings/costs, other case, prior gold or child. All resource/obligation
cells must be resolved REQUIRED, HELPFUL_ONLY or UNNECESSARY. Necessary semantic
units have explicit task/repository basis and exact evidence alternatives;
minimal witnesses, task sufficient unions and indispensable resources are derived
without treating changed files as gold. Gap findings can qualify sufficiency and
must never turn conditional task satisfaction into unconditional satisfaction.
One same-primary audit is required; no reconciliation or second reviewer.

Filesystem/schema allowlists and exact packet preservation are mechanical.
Behavioral blindness and designated model routing remain attested; this is not
OS-level secrecy or independently verified host routing. Terminal text and .local
handoff are never scientific authority. Scientific output builders verify complete
cells, exact identities/spans, alternatives, witnesses and hashes in a separate
process. Original seven primary artifacts are imported byte-for-byte.

## Future analysis and economics

Gold utility is ordinal REQUIRED > HELPFUL_ONLY > UNNECESSARY; no numeric utility.
Target vs original predecessor yields BENEFICIAL, NEUTRAL or HARMFUL. Strong benefit
is REQUIRED vs UNNECESSARY; strong harm is the reverse. These are counterfactual
local diagnostics only, with zero actual rank modifications.

Qualified case category is QUALIFIED_STRUCTURAL_DISCRIMINATION_SIGNAL for >=1 strong
benefit and zero strong harm; QUALIFIED_STRUCTURAL_DISCRIMINATION_CONTRADICTED for
the reverse; QUALIFIED_MIXED_STRUCTURAL_DISCRIMINATION_SIGNAL for both;
QUALIFIED_NO_MATERIAL_STRUCTURAL_DISCRIMINATION_SIGNAL for neither. Join/provenance
failure yields no scientific category. There is no formal cohort gate or significance
claim: three cases are development evidence.

D reports verdict x useful(R/H)/unnecessary source, grounded-source useful rate,
unnecessary admissions, useful rejections and useful/unnecessary uncertainty. For
BROAD and QUALIFIED it reports target R/H/U, useful rate, REQUIRED-in-A support,
original pair B/N/H and strong B/H. Lexically absent REQUIRED is baseline non-reach,
not a structural failure or rescuable evidence under these A-only channels.
Failure diagnostics: GROUNDING_FALSE_POSITIVE (grounded/U),
GROUNDING_FALSE_NEGATIVE (negative/useful), GROUNDING_UNCERTAIN_USEFUL,
STRUCTURAL_TARGET_NOISE_AFTER_GROUNDING (grounded useful source/U target),
STRUCTURAL_SIGNAL_ABSENT_AFTER_GROUNDING (no qualified strong-beneficial pair).
They do not supersede formal case categories or create a cohort gate.

Capture per obligation A size, broad distinct sources, grounding cells, disclosed
source bytes, packet bytes, model tokens with explicit availability/missingness,
grounding wall time, verdict counts, broad/qualified targets, qualified targets not
themselves grounding sources and their bytes, deterministic projection time. Retain
per-worker timing and total B/C/controller critical paths. Deterministic online
A/projection descriptive target: median <=250ms; >1s nearest-rank p95 is a concern.
Model time is separate; no model latency gate or prospective efficiency claim.
Per-obligation model token/time attribution is unavailable inside a shared case
batch; retain actual case totals and obligation-specific content bytes rather
than allocating invented costs. The non-scientific timing command summarizes
controller progress logs separately, with explicit missingness. Its FINAL snapshot
excludes the subsequent push; the same summary can be read after completion for
full wall time. These replaceable logs never establish scientific validity.

## Adversarial prospective review

Locality may explain the oracle association; source/target correlation need not be
incremental relation information. Grounding may recreate full relevance adjudication
and cost as much as evaluating A. Grounded sources can reference incidental details;
tests can reference implementation incidentally and docs can be grounded yet noisy.
References may add little after understanding the source. Wording may bias Sol;
excluding queries can lose acquisition specificity, but O explicitly retains all
task-relative criteria. Including queries would import Retrieval bias; freeze their
exclusion uniformly. Uncertain exclusion can destroy recall; retain its potential
support descriptively. Sparse fresh relations can legitimately yield no signal.
Sol may not reproduce oracle separation or may be operationally too costly.
None permits tuning, case substitution or treatment repair after results.

Maintainer interpretation will distinguish cleaner useful evidence warranting a
later CONSUMPTION experiment, precision/recall/cost tradeoffs needing stronger
Localization semantics, or failed runtime replication arguing against near-term
Reference pursuit. No interpretation is predetermined or production authorization.
