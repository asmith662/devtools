# Source-quality mechanism diagnostic

**POST_HOC / ORACLE / NON_GATING / NOT_RUNTIME_AVAILABLE**

This separate non-installable experiment package decomposes the completed direct
Reference discrimination DEVELOPMENT result using same-obligation frozen source
and target gold. It is not a Stage D amendment, new prospective experiment,
scientific gate, runtime feature, source filter or promotion policy. Source gold
is unavailable to a deployable qualification rule. No prior scientific files or
their published interpretation are modified.

The owner is a bounded experiment report of factual captured relationships and
semantic adjudication labels. Allowed dependencies are existing experiment
artifact/managed command/normal sealed verification helpers and the frozen
Stage D join/decision contracts. No framework abstraction, public API, package
ownership, durable schema or dependency direction changes. No promotion evidence
is claimed. Documentation impact is limited to this package and its navigation;
architecture/backlog and prior historical results retain their authority.

Inputs are anchored to published Stage D commit
`2f902a117e89f71a6b86f27259702604c7612be4`, with Stage C import and Stage B proof
anchors authenticated by its existing normal verifier. Scientific acquisition,
BM25, RI/Reference derivation, native deep replay, graph/PPR/RRF, reranking,
semantic models, historical children and confirmation/reserve are never invoked.
Only explicitly named scientific projections are read; no historical holdout or
implementation inspection is needed.

Primary unit: distinct (case, exact frame, obligation, source, target) pair.
Secondary unit: qualifying captured native Reference occurrence. Target partition
unit: (case, exact frame, obligation, target), with REQUIRED-source precedence,
then HELPFUL_ONLY-source without REQUIRED, then only UNNECESSARY sources.
Utility remains REQUIRED > HELPFUL_ONLY > UNNECESSARY; descriptive useful grouping
creates no semantic label. Local outcomes retain the original predecessor.

Every scope (cohort, case, obligation) exposes counts, row/column percentages,
useful-source collapse, target partition, original pair outcomes and exact source
rank/target rank/distance distributions. Percentages with zero denominators are
undefined, not zero. Rank distributions sample each distinct pair once. Density
counts resources within their exact case/frame/obligation identities; targets may
appear under more than one source label, so those density columns need not sum to
the target partition. Occurrence repetition never weights the primary diagnostic.

Run once:

`uv run python -m experiments.structural_discrimination.post_hoc.source_quality.execute build`

BUILD refuses any existing generated output. Then run in a separate process:

`uv run python -m experiments.structural_discrimination.post_hoc.source_quality.execute verify`

VERIFY authenticates original published bytes, exact identities/provenance and
all original categories/totals, reconstructs all diagnostic outputs and compares
their bytes without overwrite. After publication, `verify --checkpoint COMMIT`
additionally authenticates diagnostic bytes to Git. Source and input hashes are
sealed acyclically in integrity.json. Operational test receipts are separate.

Focused tests mutate copies/in-memory inputs and outputs. They reject missing or
duplicate gold, foreign frames/obligations, malformed provenance, invalid rank
eligibility, self edges, count drift, incorrect groups/cross-tabs/partitions and
output integrity tampering. No tests re-execute scientific acquisition.
