# Independent blind semantic packets

Packet construction requires all three completed captures to authenticate from
the same accepted treatment commit and clean synchronized main. Only after that
boundary does it project the exact Stage A blind specifications/resources. It
never reads native capture returns, rankings, annotations, pairs, child holdouts
or gold to author a semantic packet. Treatment validation returns are used only
to establish permission to publish, never as packet content.

Each packet has exactly README.md, integrity.json, manifest.json,
resources.json.gz and validate_packet.py. The standalone validator is specialized
only with that case's exact blind payload/task/obligation/gap/frame digests and
counts. It contains no other case or evaluator identity. Original repository
text is preserved even if it naturally mentions retrieval: metadata allowlists
and fixed digests exclude treatment leakage without deleting repository evidence.

One fresh mutually isolated GPT-6 Astra / High primary per case is recorded,
not started. No automatic second reviewer or reconciliation. Preparation and
validation create no semantic gold. Case 0019's frozen provider-option gap stays
unchanged. Complete resource-by-obligation judgments must retain uncertainty,
positive spans, units/support alternatives, minimal witnesses, sufficient unions
and indispensability; changed child files are never relevance gold.

`python -m experiments.structural_discrimination.stage_c.packet build --checkpoint TREATMENT_COMMIT`
double-builds each independent packet, checks byte equality and exclusive
publication, and writes repository publication provenance outside the blind files.
Commit/push that checkpoint before running:

`python -m experiments.structural_discrimination.stage_c.packet sterile --checkpoint PACKET_COMMIT --destination-root C:\Users\recoveryadmin\CodexSterile`

Sterile directories are fresh, named by case/archive hash prefix and contain only
the five sealed files. Copy bytes must equal their published Git blobs; reject
existing directories or reparse points. Each validator runs with python -B using
the managed command substrate, without repository imports or model launch.

The accepted packet commit externally anchors publication/source/file digests.
A packet's own manifest does not independently establish authority. After future
adjudication outputs exist, authenticate the original five sealed inputs separately
from scientific outputs; the exact-five assertion is an initial-workspace rule.
