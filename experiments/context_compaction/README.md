# Adaptive Context continuation assessment

One authored history, three predeclared treatments, one primary attempt each.
This combines accumulated acquisition metadata and semantic working-state
pressure. It is not another attempt at frozen local coding cases 0001–0003.
See [protocol](protocol.md); results and collection manifest are separate.

The framework owns projection, auxiliary inference, coding continuation, source
admission, checks and custody. The experiment composes those APIs, observes real
local calls and independently grades candidates. No application coding loop is
used. Profile configuration is reused from the established local service.
