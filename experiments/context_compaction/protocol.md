# Frozen protocol: adaptive-0001

## Questions and treatments

H1: deterministic omission buys capacity without auxiliary inference. H2: real
local notes preserve a rejected hypothesis and its observed basis. H3: notes
improve actual coding continuation enough to justify their cost. H4: a bounded
host policy spends only when useful original records would otherwise be omitted.

One authored event-accounting task combines both pressure types. Retained native
metadata records are explicitly authored fixture input, not claimed earlier live
model activity. Inventory/search verbosity models accumulated redundant metadata;
it is not a measurement of natural model behavior. The rejected hypothesis is
independently executed before freezing. Current baseline check and exact source
reads execute through existing framework operations. No prior source edit occurs.

One trial in fixed order A, B, C; no resampling or settings changes:

- A: deterministic projection, trigger 24,000 bytes, target 12,000, hard 32,768.
- B: same projection, one explicit semantic request before continuation.
- C: same projection, adaptive pressure 24,000; host values the search/probe
  records; reserve 6,144 bytes. No automatic retry after failed summary.

Summary disclosure/replacement is only the original historical search exchange,
indices 3 and 4. The selector withdraws replacement permission after a source
snapshot change. Recent source and current failed-check feedback stay exact.
No hidden test, reference patch or grading script enters either model's input.

## Envelope

Existing Qwen3.8-27B UD-IQ4_XS llama.cpp profile, model alias qwen38-local,
32K capacity. Existing instruct sampling unchanged. Acting output 4,096 tokens,
auxiliary output 2,048; thinking disabled. Complete host input <=32,768 bytes;
provider measured input <=28,160 tokens. Summary input <=24,576 bytes, output
<=4,096 bytes, 180-second auxiliary timeout, at most two auxiliary invocations.
Each continuation: six acting requests, two edit proposals, one possible repair,
16 Tool actions, 240-second acting call timeout, 1,200-second whole-run timeout.
Source regions <=8,192 bytes; resulting source <=12,288; aggregate edits <=24,576.
Only reducer.py editable. rules.py is read-only. Fixed focused command only;
no arbitrary shell, publication, scope growth, model fallback or model downloads.
Only independently authored task directories under ignored local state mutate.

## Independent scoring fixed before inference

Capacity: complete original/selected bytes, actual measured tokens, native Prompt
validation and exact source bindings. A fit is not engineering success.

Semantic fidelity (B/C): each generated claim adjudicated against the frozen
probe/history. Required useful facts: global event-ID suppression is rejected;
two different streams may share an ID; rejected events must not reserve an ID;
the current implementation still fails; no edit/check success is invented.
Report each preserved/omitted/contradicted, unsupported additional claims, and
whether record references pass exact structural/provenance checks. Schema pass
does not certify paraphrase truth. No post-hoc score threshold creates success.

Continuation: archive exact candidate, focused checks, five held-out literal
cases; independently inspect scope, minimality and intended behavior. Success
requires all focused and held-out assertions plus honest terminal/custody state.
Report all failures and incomplete treatments. Original source must be restored.

Count model-chosen source reads/checks separately from pre-freeze host seeding and
automatic candidate validation. Report repeated reads, proposals, repair feedback,
native IDs, known effects and uncertainty; no inference of hidden reasoning.
Compare usage and elapsed time, not monetary cost when no price applies.

This single paired starting history cannot establish general threshold optimality,
causal model effectiveness or a success rate across independent engineering tasks.
Trajectories may diverge after the first response. No forced failed edit.
