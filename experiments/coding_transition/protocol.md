# Investigation-transition-0001 protocol

One read-only local-model diagnostic follows the failed B-0035 task-navigation
attempt. It is not a new full maintenance attempt or a repair of frozen evidence.

The genuine objective is retained in objective.md. The host selects seven exact
implementation/contract units using existing RI symbol representation and
ScopedSourceTool. This intentionally controls source availability; it does not
measure autonomous discovery. All units are public source or public diagnostic
assertions. No reference patch or held-out oracle is disclosed. Source identities,
the exact initial request, schemas, settings and scoring are frozen before entry.

The model may select find_source, read_source_unit or read_source, or end with an
ordinary assistant response. No edit/check descriptor is available. Non-read
calls are refused before dispatch. The shared coding process remains the only
loop. Its required nonempty objective/custody surface confers no mutation authority;
the experimental effect collaborator refuses every write and restoration only
checks equality. No worker command or candidate validation is expected.

Maximum envelope: four acting requests, six selected acquisition actions, zero
auxiliary requests, zero edits/checks, 90 seconds per call, 360 seconds agent wall
time and 420 seconds outer controlled operation. Existing limits remain 32,768
complete-request bytes, 28,160 measured input tokens, 4,096 output tokens and
8,192 bytes per disclosure. The current pinned Qwen3.8-27B llama.cpp profile and
sampling settings remain unchanged, including thinking disabled. No retry,
fallback provider, model download, setting adjustment or full ten-call trial.

Predeclared behavioral success requires a concrete next engineering action or a
specific genuinely missing contract/blocker supported by disclosed source.
Independent review cites the actual response and source. Generic readiness,
smaller Context, fewer reads or an unsupported implementation suggestion do not
pass. Only repeated investigation, false completion or no specific next step
before the limit is a failure. Serving/capacity/custody obstruction is qualified
separately. A read-only success is not B-0035 completion, patch correctness or a
causal estimate of the status annotation's value.

`host.py preview` is deterministic source/terminal preflight, not live evidence.
After committed protected validation, `host.py freeze` authenticates the configured
service and freezes inputs. `host.py run` permits one primary entry. Artifacts are
written only under ignored `.local/implementation-transition/run` while Checkout
is held; retained publication happens only after release. No original experiment
is reexecuted. New entry/outcome receipts preserve uncertainty if transport fails.
