## Predeclared decision gate

A usable response is a valid source-grounded edit proposal, a relevant native call
for genuinely absent source, or a concrete source-supported engineering action or
specific justified blocker. Check native arguments, disclosed ranges, identities,
and claims of effects. A repeated fully active read without justification, generic
plan, unsupported repository claim, fabricated receipt, or unfinished output-limit
reasoning is unusable. Output-limit termination is not automatically disqualifying
if a complete valid action actually exists, but unfinished semantics are rejected.
Schema-valid text alone is not source-supported correctness.

under identical criteria. If neither is usable, stop with no coding episode and
recommend a controlled alternative local coding model, not larger xhigh ceilings
