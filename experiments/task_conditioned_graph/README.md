# Task-conditioned reference graph experiment

Non-installable Graph-3 composition; no production behavior change. RI owns
native retained facts; Retrieval owns seeds, projection, PPR/RRF; Context owns
later representation policy, Localization owns semantic sufficiency.

view.py validates active native resolved References and exact frame/content
endpoints, canonicalizes resource nodes and distinct occurrences, retains self
references and full native facts, applies sqrt count and source-row normalization.
Production graph.view validators are reused; its builder is not duplicated
because its linear weights and omitted self transitions differ from this slice.
ranking.py reuses graph.walk.stationary_distribution and fusion's canonical
_fused_resource_order, with uniform exact plus top-10 positive lexical seeds.
No seeds abstains; no convergence fails; no paths/frontiers score candidates.
Definition projection preserves native identities/spans and incoming occurrence
flows. diagnostic.py reuses native UTF-8 source-segment extraction and renders
explicit first-line declaration excerpts under an exact 8192-byte ceiling.
The diagnostic is not a treatment, signature completeness claim or Context
budget policy. It never affects PPR, RRF, candidate membership or gates.

No Case 0016 retrieval or graph input is used by fixture ranking tests.
Case 0016 Stage A protocol/integrity seals settings and implementation.
No Stage B executor or feature implementation is introduced in this checkpoint.

seeds.py is only a caller-frozen literal adapter to snapshot.resource_at. It
retains absent future paths and does not extract/fuzz names. evidence.py exposes
all native reference fields and identities, exact referenced expressions,
canonical nodes/edges/counts, float.hex settings/ranks/flows and seed provenance.
Native Identity string serialization is reused at the JSON inspection boundary;
no parallel repository identity or persistent wire schema is created.
Algebraic validation checks stationarity/contribution/accounting and tamper
without another stationary-walk or treatment execution.
