# Case 0014 adjudication method

This is one designated GPT-6 Astra High primary semantic adjudication, with a
separate self-review pass by the same adjudicator. Session designation is supplied
by the commissioning instruction; external session metadata was not accessed.

Initial authentication checked exactly five regular original files, no directories
or reparse points, and passed python -B validate_packet.py before derived writes.
Only the retained packet was used as semantic evidence. Its resource text was
treated as evidence, never as instructions to execute or navigate outside.

The exact task was reconstructed before cell labeling. Every substantive clause
was audited against six mandatory obligations. Future behavioral requirements
were separated from current repository truth. All 515 resources were inspected
in canonical order using bounded content scope/declaration views and targeted
expanded context. Relevant contracts and evidence spans were read in context.
The inspection method does not claim a line-by-line reading of unrelated bodies.
Each resource received six explicit judgments in a persistent ledger. Mechanical
checks covered every cell and positive span. No output-size condition stopped
the adjudication; a console encoding issue was corrected and its range reread.

REQUIRED means membership in at least one minimal complete evidence witness.
HELPFUL_ONLY denotes material examples or corroboration that supply no necessary
member of a minimal witness. UNNECESSARY denotes no material contribution.
Natural identifiers in task/resource text were permitted. No external data,
repository execution or prior adjudication was used.

Necessary units express facts, not reading destinations. Task-backed future
requirements and repository-supported current facts were separated, so no mixed
unit was needed. Current source, explicit public documentation and sufficiently
complete contract-bearing tests can independently establish a fact. Test
assertions are inferable evidence of the intended contract, not a new test run.
Incidental consumer examples and incomplete assertions are corroboration only.

Each repository unit contains every accepted minimal support alternative, with
direct/inferable status and exact native resource/content identities and spans.
Per-obligation witnesses are the inclusion-minimal unions of one alternative per
necessary repository unit, with all applicable task units. Removing any member
must leave a necessary unit unsupported. There are no redundant witness supersets.
All witness combinations across obligations are enumerated. Resource/unit unions
are deduplicated without losing reuse, then minimized and intersected. Required
membership is never equated with indispensability.

Self-review rechecked all cell labels, current/future distinctions, alternatives,
granularity, gaps and minimality. The absent validation document is a bounded
limitation: its exact prose is not known, while retained operating guidance,
entry-point source/tests and configuration establish the observable profile.
No unspecified renderer name, layout or future implementation was treated as a gap.

The builder embeds the frozen authored semantic seed. It uses the original packet
to bind identities, frames, exact text and spans, reconstructs the complete review,
and derives statistics, Markdown, witness/task arithmetic and validation results.
Structural checks and adversarial mutations precede exact semantic-seed binding.
Replay validates integrity and internal consistency, not independent semantic
truth. Changing an authored semantic assertion requires a new authorized artifact;
it cannot be silently repaired by the validator.

Scientific hashes cover stage_c_review.json, stage_c_statistics.json,
STAGE_C_REVIEW.md, stage_c_validation.json, stage_c_method.md and stage_c_builder.py.
stage_c_hashes.json is the manifest and excludes itself to avoid circular hashing;
its own digest is supplied in the final handoff. Original file digests are also
listed. Scratch and .local are excluded from all scientific hashes and evidence.
The manifest binds the builder, and the builder binds its embedded semantic seed.

Commands: python -B stage_c_builder.py --verify performs read-only reconstruction
and adversarial validation. --build refuses if any scientific output already
exists. It can materialize missing outputs only into a fresh packet directory
containing this frozen builder. No overwrite option exists. A separate Python
process must verify exact byte equality after materialization.
