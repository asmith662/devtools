# Frozen protocol: reliability-0001

One task, one treatment, one primary attempt. Verify explicit llama.cpp
`response_format: {type: json_object}` for an auxiliary summary, actual summary
consumption by a subsequent acting request, and source-bound usability. A natural
bad read may recover; none is forced. A correct edit is a separate outcome.

The task is occupied-time accounting for a room reservation system. Three
authored Python files expose implementation, interface contract and focused
checks. Only occupancy.py is editable. The objective does not contain a patch.
An independently executed rejected-hypothesis probe is retained as prior
investigation, explicitly authored by the fixture host rather than a previous
live model. Its distinctive nested-window counterexample is not repeated in
the objective. Summary fidelity is assessed against that original probe, not
against citation membership alone.

Use existing Qwen3.8-27B UD-IQ4_XS, 32K llama.cpp profile, unchanged instruct
sampling and thinking disabled. One explicit summary, at most 2048 output
tokens, 4096 output bytes, 24576 input bytes, 180 seconds. Six acting requests,
4096 output tokens each, two edit attempts, one possible repair, 16 Tool actions,
240 seconds per call, 1200 seconds total. All effective requests <=32768 bytes
and measured inputs <=28160 tokens. Source disclosure <=8192 bytes; edit region
<=8192, resulting source <=12288, aggregate <=24576. No shell, publication or
scope expansion by the model. No inference fallback or resampling.

Deterministic projection: trigger 12000, target 6000, hard 32768. Explicit
semantic replacement covers only the original probe exchange, indices 1 and 2,
while the initial source snapshot remains current. No adaptive threshold changes.
The raw response is retained. No fence removal or JSON salvage is allowed.
Summary selection/adoption and actual acting consumption are scored separately.

Frozen focused checks and a separate undisclosed oracle assess overlap, clipping,
nested intervals, ordering independence, adjacency, empty/reversed intervals,
negative coordinates, input immutability and fractional endpoints. Baseline must
fail. The independent reference oracle is a small integer-grid coverage oracle
for generated integer cases, with separate literal fractional expectations; it
is never model input. No intended implementation is disclosed.

Record actual requests, native call IDs, disclosed source, check results,
candidate bytes, restoration, usage, latency and unknown effects. A fit or
adopted summary does not prove semantic benefit. This single unseeded treatment
cannot establish a causal advantage over deterministic projection.
