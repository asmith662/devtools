# Decision-checkpoint-0001

One frozen sample in each of four cells: B-0035 A, B-0035 B, atomic-edit control A,
atomic-edit control B, in that fixed order. A advertises existing bounded source
search/read schemas with automatic choice; B uses tools=(), so no provider tools
field is sent. The model-neutral request API has no explicit tool_choice setting.
Task messages, exact source, decision instructions, model, sampling and bounds are
identical within each pair. Each call starts stateless; generated answers are not
shared. Template/schema costs and cache effects can differ and are measured.

B-0035 uses current RI symbol units and actual scoped Context materialization,
retaining all seven exact disclosures continuously for the single response.
No hidden oracle or reference patch is disclosed. The control characterizes an
existing engineering contract: overlapping edit batches must be admitted atomically.
Independent interval arithmetic and the actual pure admission function cross-check
that expectation before inference; this is not a general oracle certificate.

Each cell has one call, maximum 4096 output tokens, 28160 measured input tokens,
32768 serialized request bytes and 90 seconds. The comparison has a 480-second
controlled inference window. No Tools are dispatched; A's first requested action
is preserved and graded. No continuation, edit, worker check, fallback, downloads,
parameter tuning or resampling. A missing/failed cell remains incomplete.

Correct means a concrete source-supported action or justified genuinely missing
evidence with no contradictory authority/result claims. Partial, uncertain,
unsupported, invalid, incomplete and Tool-request outcomes are separately graded
using the pre-frozen criteria. Prose length is not a competence score. The expected
control answer and supervisor rubric are outside the model's source scope.

Original requests, actual provider JSON payloads, raw response body bytes,
normalized responses, termination and known usage are retained. Raw HTTP framing
is not captured. Artifacts remain in ignored staging during Checkout ownership,
then are copied byte-for-byte after release. No production code is changed.
The runner is retained as runner.txt for reproducibility, not a supported command
or authority to repeat this closed evaluation. Only the authorized four calls may
enter. One sample per cell cannot estimate a success rate or establish causality.
