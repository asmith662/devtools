# Task-local working Context

`WorkingNotes` retains role/task/episode-bound provisional claims, exact source
support, unresolved questions, relations and explicit revisions. `SourceBinding`
borrows canonical observed resources and disclosed ranges. Literal quotation
verification and trusted-host semantic attestations remain distinct.

The [development contract](../../../../../docs/development/agent-working-notes.md)
defines bounds, source freshness, reconstruction and the independent reviewer
consumer. This is immediate task state, not cross-task Memory or RI
DerivedKnowledge. Resource/source owners retain observation and acquisition;
Context selects the working view, and the consumer's existing episode owns
durable capture. Model-written text never becomes verified merely by recording it.

The package depends on canonical repository resource/snapshot values and standard
library support only. It does not import Agents, Tools, native administration,
Persistence or model providers. A later coding consumer can reuse it without a
reviewer dependency or a new source ledger.
