## Ownership and correction

`development_task._structured_edit_patch` remains the exact region/newline/match
and diff primitive. `edits.admit_transaction` remains the coordinated admission
owner; `admit_observed` resolves the opt-in path/reference interface into it.
`PatchProposalError` retains its class, historical message and ValueError behavior,
with an optional host-owned `details` dictionary. `coding_loop._turns` carries it
into existing correlated native Tool results and `tools.json` evidence. There is
no second validator, source store, patch repairer or execution authority.

The old compound errors truthfully refused invalid text but erased the distinctions
among size, empty/NUL text and no-op edits. Transaction catches lacked the original
component index. The native adapter also reused the first call's ID for composed
admission; refusal details now point back to the actual offending native call.

Details include a one-based component index, authorized path, stable reason,
old/new UTF-8 byte counts and applicable bounds, normalized-byte counts where
needed, crossing aggregate measurements, overlap indices and observed versions
or exact absence where actually disclosed. No source snippets are echoed.
`ContextTools.observed_matches` reuses the current observed-union semantics of
`observed`; repeated observations do not inflate counts. Counts never inspect a
different owner or undisclosed text. An unauthorized path produces no path,
source identity or match information. Very long caller IDs use a diagnostic hash;
the native call/result IDs themselves remain unchanged.

All existing admission order and limits are retained: 16 components, 4096 bytes
per old/new region, 8192 combined edit bytes, 16384 combined patch bytes and 32768
source bytes. No splitting, trimming, approximate matching or partial application
is introduced. The first existing authoritative blocking check wins. Combined
patch/source limits name contributors rather than inventing a unique culprit.
Unexpected occupation/source drift remains a terminal host-integrity failure;
stale submitted versions and missing/stale absence authority remain refused.
