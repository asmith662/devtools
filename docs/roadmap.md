# Roadmap

1. `PATH-1A` — path primitives, parsing, resolution, and dot-path conversion
2. `TIME-1A` — timestamps, durations, parsing, and `Stopwatch`
3. `SYSTEM-1A` — operating-system family detection
4. `COMMANDS-1A` — immutable command execution and bounded streaming
5. `IDENTITY-1A` — UUID-based identity primitives
6. `REGEX-1A` — immutable regex match and search primitives
7. `FILESYSTEM-1A` — immutable file models and frozen JSON models
8. `JSON-CODEC-1A` — JSON decode/parse and encode/serialize
9. `FILESYSTEM-2A` — codec-backed generic filesystem reading and writing
