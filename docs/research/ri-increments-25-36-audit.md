## Test quality, reuse and compatibility

The full test-body review covers real observed import/reference/package fixtures;
negative ambiguity, shadowing, foreign snapshot and seed-exclusion cases; lexical
numerical expectations; token coverage; fake encoder masks/pooling; neutral
population coverage; and altered-input/label failures. It also identifies limits:

- Many tests call the same result/population builder and compare to retained JSON.
  They establish reproducibility, not independent label truth or effectiveness.
- `SimpleNamespace` relationship fixtures and synthetic location spans are valid
  projection/accounting checks, complemented by actual source derivation tests.
  They do not qualify native source identity or Unicode coordinate correctness.
- The25 suite missed the bijective-swap negative; the28 suite's Unicode identifier
  does not challenge Unicode nonphysical line separators. Existing fixture and
  integrity proposals now specify those real-owner negatives.
- Experiment controllers have no generic cancellation journal/recovery guarantee;
  CLI exceptions and sequential writes cannot prove no work or no partial file.
  Preserve frozen controllers; do not promote them as WorkCycle replacements.

Repeated work is concrete:29 parses function/import/AST views and resolves each
alias;27 rebuilds lexical fields/indexes and uses repeated `addresses.index`
inside tie ordering; current source search rebuilds filename evidence through
native BM25. Some repetition authenticates source freshness or preserves an
independent control. No workload timing was measured, so no cache/speedup claim.
Existing measured-reuse proposal requires two current consumers and exact input
closure before optimization.

Small future helpers could share full semantic judgment coverage, state counts
or source-bound presentation. Existing `retrieval_judgment_coverage` already
serves29/30/34/35/36. Different canonical JSON encodings/newlines and declaration,
binding, source and witness identities must remain distinct. No generic Evaluation
framework, universal fixture or controller base is justified by repetition alone.
