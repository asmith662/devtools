# Evidence-verified reviewer and active working Context

**Verified outputs reached Qwen; the enhanced reviewer still accepted the
defective candidate.** The baseline withheld acceptance for insufficient
evidence. Neither identified the real empty-heading defect, and neither proposal
was admitted. Seven genuine generations ran under fresh automatic standing
grants, with **zero per-run operator approvals**; the eighth reserved call was
unused after the enhanced condition's frozen stop rule.

This study follows the [unattended procedure comparison](reviewer-notes-procedure-results.md).
The implementation is published at `f1852d662050a65623933b90771826f62f9dc9fa`.
Its [contract](../development/agent-working-notes.md#active-claims-and-public-behavioral-observations)
and [qualification evidence](code-audit/reviewer-evidence-20261105/manifest.json)
separate literal quotations, behavioral observations and fallible interpretations.

## Production correction

The existing native reviewer can prospectively receive a host-frozen
`public_observations` catalog. The trusted host executes an explicitly authorized
`FixedCheckPlan` through `FixedCheckTool`, then freezes complete known output with
the exact candidate/baseline content identity, definition/input hashes, actual
stdout/stderr bytes, command status and reproducible receipt. Stale sources,
unknown effects, collection errors and incomplete output are refused. Declared
inputs are a scoped correspondence claim, not universal dependency closure.

`inspect_public_check` only selects one of those recorded observations; it cannot
execute code, select new inputs, author tests, install a candidate or grant
authority. `reopen_working_note` retrieves a retained sequence under its exact
task, reviewer and episode, preserving provisional/stale/disputed status. Both
consume existing acquisition budgets and disappear during reserved synthesis.
Fresh call IDs, prompt/capture bounds and strict proposal validation remain.
Historical subjects without a catalog gain neither callable.

Shared `WorkingNotes.project` prioritizes current non-source claims over literal
read quotations. Whole selected records remain chronological. Unfit active
sequences are explicitly listed for recovery; retained checkpoints are unchanged.
No hypothesis becomes verified merely by recording or projecting it. Source
quotations verify their bytes; fixed checks verify their recorded observations,
not every causal explanation or the complete engineering obligation.

The shared interface contains no Markdown rule or model-specific branch. Its
first bounded public probe inspects the archived regex literal and applies the
named `text`-group/`strip` producer operation on four fixed public inputs. It
never imports or executes the candidate module. Its output is limited producer
evidence, not comprehensive Markdown acceptance.

## Evidence use and factual judgment

The [fixed public observation](code-audit/reviewer-evidence-20261105/public-result.json)
records `# C# → C#`, `# C# # → C#`, `# Title # → Title`, and **`# ## → ##`**.
The public task requires the last title to be empty. Execution success says the
probe completed; it does not say that the candidate meets the task.

The enhanced reviewer selects the full 676-character observation on turn one,
receives its complete native feedback on turn two, then correctly reproduces all
four outputs during turn three. It explicitly cites retained source note 1 and
withdraws both historical false positives using the real normal-case outputs.
Those are real improvements in evidence acquisition/use within this episode.

It nevertheless calls `# ## → ##` “all attached” and task-compliant, inferring
preserved empty-title/lookup behavior from unchanged consumers despite the changed
producer. Its raw proposal accepts with outstanding gaps. Relevant authenticated
evidence was present and explicitly used: the remaining error is contract
interpretation/reasoning in this tested configuration, not missing output or
serialization alone. It is not proof of a universal model capability limit.

The baseline withholds acceptance and requests execution evidence. This is safer
than false acceptance, but it still misses the genuine defect under the unchanged
grader. No blocking defect is invented by either arm.

Strict admission remains separate. The baseline's note is accepted as provisional,
but its verbose `assessed_obligations` value is not the exact obligation name.
The enhanced response starts with note JSON followed by prose: actual admission
stops at `JSONDecodeError: Extra data`. Its visible fragment also includes forbidden
`verification`/`status` fields; it is never repaired or adopted. Independent
host-only inspection of its raw proposal also rejects invalid obligation names.
The P3 fixture lacks `public-checks`, `acceptance` and `custody` references required
for acceptance; none are fabricated. Successful native proposal delivery and
correct candidate/subject IDs therefore establish neither admission nor truth.

## Working Context result

The baseline authors two provisional inspection notes, explicitly revisits note 1,
and records a final provisional conclusion. Source support is unanchored; none
becomes a verified semantic fact. Actual saved-state reconstruction works, but
legacy final projection retains only literal reads 4/5 and evicts active hypothesis
3. The final newly emitted note was never available for an additional model turn.

An [offline replay](code-audit/reviewer-evidence-20261105/offline-projection-replay.json)
authenticates that exact pre-final checkpoint and completed source bindings,
then applies current selection without another generation. It keeps sequences
1/3/4/5 in **7,210 bytes**, including still-provisional active hypothesis 3, with
no active omissions and unchanged source evidence. This demonstrates the actual
selection correction, not a counterfactual claim of better model judgment.

The enhanced model authors **zero valid notes**. Its late conclusion attempt is
malformed and remains unadopted. Both host-created literal observations survive
reconstruction/projection, with no omission at turn three; later use of source
note 1 is explicit. There is no live evidence of retaining or revising its own
hypothesis, so improved authored-memory effectiveness cannot be claimed.

## Validation and operational reconciliation

The committed implementation passed **4,456 tests, two opt-in live tests skipped,
100% production branch coverage**, complete unchanged inputs and native exit zero.
The managed run took 4,350.96 seconds under a 7,200-second deadline. An earlier
wrapper stopped at 532.40 seconds because repeated Windows atomic stdout-log
replacement failed. Its failed receipt/trace are preserved; no protected child
remained. Saving logs once at terminal completion corrected only that local
wrapper. The recovered run uses identical committed production inputs/profile.

Stable final focused testing passes 57 tests; Context passes 48 at 100% branch
coverage. All 147 affected tests also pass, but that earlier receipt detects
test-cosmetic input drift and is not used as final qualification. Strict mypy
checks 645 files; maintained Ruff/format check 797 files; layout and diff pass.
The [validation record](code-audit/reviewer-evidence-20261105/validation.json)
preserves receipt hashes and these limits. Evidence-only closeout adds no
production executable input and does not repeat the protected suite.

An initial live preflight's fixed probe returned before the receipt constructor
rejected a 211-character concatenated label (canonical `CommandOrigin` permits
128). Its failed grant remains consumed and unchanged; no missing original
stdout is invented. The source and fixed code establish known read-only effects.
The corrected prospective packet uses the authenticated entry digest as the
bounded receipt, retaining the full grant separately. One fresh automatically
authorized measurement captures complete output. Thus two host probe executions
occur, **zero model generations before the qualified freeze**, and seven after.
This caller correction changes neither production nor scoring; the
[reconciliation](code-audit/reviewer-evidence-20261105/preflight-reconciliation.json)
retains the original failure. No uncertain model effect is replayed.
