## R1.5 retrieval diagnostics

[Adapters](../../experiments/retrieval_diagnostics/adapters.py) project native
canonical/R1 results or frozen rows, retaining snapshot/corpus, occurrence/content,
query, lane, obligation and configuration. Missing field statistics are rebuilt
using the existing owners. [Mechanics](../../experiments/retrieval_diagnostics/mechanics.py)
checks query analysis, field/source equality, lengths/average, query postings,
captured terms/scores, row order/ties, ranks and complete positive membership.
It records exact whole/subtoken character spans and three bounded examples per
term; these are lexical evidence, not Python AST UTF-8 coordinate authority.

Optional independent judgments remain optional. Unjudged and UNRESOLVED are not
negative labels. Required/useful yields are denominator-qualified diagnostics;
global lane explanations without obligation judgments cannot certify harm.
Structural/role/exact supports retain positive native references without proving
relevance, runtime behavior or satisfaction. Absent supplied support is NOT_ASSESSED.

Failure attribution establishes substantial ranking burden only with REQUIRED
gold, positive rank and the declared unnecessary-overtaker threshold. Partial
hidden lexical cues differ from a positive-reach rescue. Common terms and length
normalization are observations, not automatic downweighting advice.
Case0009 dogfood explains the **same** 37 required cells: eight A/seven B local
burden findings, twelve partial hidden matches, zero positive-reach rescues.
It is instrumentation over the original experiment, not another effectiveness run.
