# Task-directed coding-host navigation

## Ownership decision before implementation

Baseline `576c3e6d3a086168c5f0ecaba93efbf73b9a2b1a` retains the completed
recovery and qualified failed Maintenance-navigation-0001 result. Ten native
empty queries paged global symbols; the descriptor explicitly offered this
default and each result supplied a next offset without a task-level browse
allowance. The objective encouraged precise reads but did not prevent this
choice. We cannot infer the model's intention or establish a ranking failure
from queries it never selected.

Agents owns an optional task-entry and exploration policy, composing the existing
source index/search and native feedback. Context retains relevance scores, units,
selection/materialization and exact provenance. Tools retains scoped navigation
and source execution. No new search algorithm, index, planner, Context history,
executor or source identity is justified.

The first request will contain a bounded **candidate view**, derived only from
the actual objective and authorized index. It is incomplete metadata, not the
complete inventory required by B-0035. Exact source must still be selected and
disclosed by a model call before editing. Lexical evidence can explain retrieval
but cannot certify relevance or task correctness.

An explicit host policy will make empty navigation search the objective, while
an explicit browse argument permits ordinary outlines/pages. Its host-selected
enumeration allowance is derived from retained calls and existing claimed Tool
actions, not a parallel mutable counter. Exhaustion returns correlated no-effect
feedback, preserves consumed action/model budgets, and leaves query/read options
available. No universal page count or forced edit strategy is imposed.

Existing unconfigured native consumers retain their surface. Source identity,
currentness, bounded partial reads, native correlation, exact active witnesses,
projection/semantic/adaptive compaction and custody remain authoritative.

## Delivered mechanism and limits

Supply `navigation=True, navigation_policy=NavigationPolicy(...)` to the neutral
host. Defaults are six candidate rows, 6144 presentation bytes, two explicit
outline attempts. These are host-selectable bounds, not universal steps. Existing
unconfigured navigation remains compatible. No task hashes or legacy Qwen policy
are rewritten. The Qwen compatibility facade still uses the shared coding process;
the separately frozen operational host explicitly opts into the new policy.

`coding.navigation` owns the policy, first-request view and native navigation
composition. The existing Tools source query bound is exposed as
`MAXIMUM_NAVIGATION_QUERY_CHARACTERS` (256). The initial search uses that prefix
of the actual objective, with exact query and `query_partial` qualification.
The entire objective remains separately present and unchanged. This simple query
selection can miss later task concepts; the model can issue a better bounded
query. No hidden target, filename or model-specific heuristic is supplied.

Existing file search selects at most two resources; scoped symbol search then
selects at most two units within each. Original native ranks, scores and up to
eight matched content terms accompany identity, kind, path, version and offsets.
Rows are deduplicated by canonical unit identity and bounded in complete JSON.
Candidates can be misleading. No relevance threshold certifies adequacy. Generic
resources retain existing file/window fallback; broad units can require partial
reads. Metadata never supplies exact source, witnesses, readiness or permissions.

The host retains one initial candidate view as host-authored Context, without
invented native calls. Its original snapshot remains explicit after edits;
stale unit references require new authorized navigation/acquisition. Native read
feedback and exact active availability continue through Context materialization
and existing projection. No second Context history or mutable navigation counter
exists. Mandatory objective plus schemas/metadata must fit complete-request limits.
An impossible minimum refuses before model entry.

With this policy, omitted/empty query searches the task prefix. `browse=true`
explicitly chooses an outline; query and browse cannot conflict. The existing
claimed action identities and retained native calls determine attempted outlines.
A host allowance can permit several pages, or none. Exhaustion returns truthful
correlated `REFUSED` feedback with `navigation_entered=false`; it discloses no
source, acknowledges only that refusal and consumes the existing action budget.
It does not rerun the call, reset budgets or disable query/read operations.
Original returned pages and calls remain in history; active feedback reports
outline attempts/limit and encourages read or refinement rather than exhaustion.

## Independent measurements before live entry

The immutable Maintenance-navigation-0001 reconstruction changes its first
complete request from 5224 to 9178 bytes. The relevant host class is selectable
immediately; one bounded exact read includes the known request-assembly method.
No metadata pages are needed first. This is an effect-free reconstruction from
the frozen snapshot and native schema, not a rescued or replayed original attempt.

The authored non-Qwen fixture uses two acting requests, one source action,
26 exact source bytes and requests of 5431/6296 bytes to edit, run a real fixed
check and restore custody. Its browse/refusal/refinement control uses six requests
and five acquisition actions under the same source authority. These are scripted
choices, not measured autonomous effectiveness.

The focused compatibility suite passed 1895 tests. New controls cover metadata
without witness credit, stale/foreign references, partial and evicted source,
non-Python/Unicode/CRLF resources, lexical distractors, absent matches, invalid host
bounds, protected presentation/complete-input overflow and correlated outline
exhaustion followed by useful acquisition. Existing cancellation/uncertain-effect
and compaction suites remain applicable; no retry semantics were changed.

A separately frozen [maintenance protocol](../../experiments/local_maintenance_task_navigation/protocol.md)
requires the committed protected gate and independent oracle preflight before
the one possible real attempt. A shortlist is not the complete authorized
inventory: B-0035 remains unimplemented by this increment.

## Pre-inference test review

The first committed implementation passed 3889 protected tests, two optional
skips and 100% configured coverage. Before model entry, a fixture assumption was
corrected: candidate metadata is located by its declared kind, rather than
reserving message slot 1 or forbidding another host metadata frame. This avoids
turning a legitimate future complete-inventory frame into false failure feedback.
Exact source, boundedness and native correlation expectations remain. Production
source and B-0035 oracles are unchanged. The final test revision is separately
committed and receives the full unchanged protected gate before inference.
